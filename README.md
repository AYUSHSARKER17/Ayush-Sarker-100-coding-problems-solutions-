## 📌 About This Repository

This repository contains **100 Python programming problems** that I solved to improve my **problem-solving skills, programming logic, and Python fundamentals**.

The problems are arranged step-by-step, starting from basic input/output and gradually moving towards loops, patterns, strings, lists, functions, recursion, and contest-style logic problems.

This journey helped me build a strong foundation for **Competitive Programming and Software Development**.
